# Sumi

A component library built on top of [shadcn/ui](https://ui.shadcn.com).

Sumi (墨) is ink — the layer you lay down on paper that turns a blank surface into
something with character. shadcn gives you the paper and the brush; this is the ink.

Public and early. Nothing is published yet.

## Status

- Repository created.
- Registry, tokens, and components not written yet.
